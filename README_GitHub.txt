CÓMO PUBLICARLO EN GITHUB PAGES
1. Crea un repositorio nuevo en GitHub.
2. Sube el archivo index.html a la raíz del repositorio.
3. En GitHub entra a Settings.
4. Selecciona Pages.
5. En Build and deployment selecciona:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
6. Guarda los cambios.
7. GitHub generará una dirección web para abrir el laboratorio.

El laboratorio funciona en un solo archivo HTML, por lo que no necesita carpetas adicionales.
